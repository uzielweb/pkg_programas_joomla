# Programas Joomla (Pacote)

Este é um pacote completo (Joomla Package) que reúne o Componente e o Módulo para gerenciamento e exibição de grades de programas (ideal para Web Rádios, emissoras e streams).

## 📦 O que está incluído?

- **Componente (`com_programas`)**: A base para gerenciar e cadastrar todos os programas, seus dias da semana, horários de início e fim, descrições e apresentadores.
- **Módulo (`mod_programas`)**: O módulo prático de frontend para exibir os programas cadastrados em qualquer posição do seu template.

## 🚀 Como instalar

Graças ao formato de pacote, você instala tudo de uma vez só:

1. Faça o download da versão mais recente deste repositório (em `.zip`).
2. Acesse o painel de Administração do seu Joomla.
3. Navegue até **Sistema -> Instalar -> Extensões**.
4. Faça o upload do arquivo `.zip` deste pacote.
5. O Joomla reconhecerá o pacote e fará a instalação conjunta do Componente e do Módulo automaticamente.

## 🛠️ Manutenção e Desenvolvimento

Se você quiser contribuir ou modificar, note que o código fonte do componente está na pasta `packages/com_programas` e o do módulo na pasta `packages/mod_programas`. Para criar o instalável para distribuição, basta compactar todo o conteúdo (junto com o `pkg_programas.xml`) em um arquivo ZIP.
